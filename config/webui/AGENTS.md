# Installed WebUI Instructions

- 本文件仅适用于已安装的 WebUI；源码仓库及 CLI 继续遵守源码根目录的 `AGENTS.md`。
- WebUI 远程操作只可选择数据库中已登记、启用且唯一确定的资产；不读取、不导入源码仓库或本机的 `hosts`，也不接受临时 SSH 地址或凭据。
- 所有 SSH 连接和远程命令必须通过已安装的 `utils/ssh_utils.py` 与 WebUI 固定工具执行。第一版只开放查看类巡检与历史报告，不开放任意命令、安装、配置或重启工具；后续新增修改/重启工具前必须展示完整动作并取得明确确认。移动、删除、停止、关闭类操作始终禁止。
- WebUI 巡检报告只写入容器数据卷内的 `WEBUI_DATA_DIR/reports`。Docker 巡检仅查询 `default` context，不改变当前 context。巡检结束后应分析报告并向用户说明关键发现、风险和建议。
- 托管密码、私钥和模型密钥不得回显或写入模型上下文、服务日志和源码仓库。远端日志和进程参数可能含秘密，只能通过已登录管理员的报告接口按需查看原文；其他响应、模型上下文与服务日志只能用受限摘要。数据库与加密根密钥分开保存；不得将真实资产信息加入 Git。
- 本文件是操作约束，不代替后端对资产、SSH 命令、报告路径、认证与凭据的运行时校验。
